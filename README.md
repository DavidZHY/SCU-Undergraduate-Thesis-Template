# SCU-Undergraduate-Thesis-Template

这是四川大学本科毕业论文的LaTeX模板，符合2026年计算机学院毕业论文（设计）要求。本人毕设使用的就是这个模板，最终获得了94分，请大家放心使用，有问题请提issue，我会及时看的。

## 模板文件结构

- `Chapters/`：包含论文各章节的源文件
- `Images/`：包含论文中使用的图片
- `Template/`：包含LaTeX模板文件，一般来说无需修改，只有下面[模板使用章节的第1步](README.md#L15)出现不一情况的时候才修改。
- `Reference.bib/`：包含参考文献列表
- `MainBody.tex`：主文档，用于编译整个论文，编译后的文档样式类似`MainBody.pdf`所示

## 模板使用方法

1. 确认老师允许最终提交PDF文件（非常重要，LaTeX转换为word格式比较复杂）。
2. 首先，请先关注学院当前年度发布的通知，里面会有一个word格式的模板，类似[docx格式模板](四川大学2026届（2022级）计算机学院本科毕业论文（设计）格式模板.docx)文件。每年的要求可能有细微变化，请先和本文件对比一下，尤其关注文档的批注（可能出现文档内容和批注不统一的情况！比如2026年的三级标题设置。以批注为准！）。
3. 将本模板中所有用中文中括号【括起来的内容】，和用英文中括号\[括起来的内容\]，替换为实际的值。
4. 开写！注意`Chapters/`目录下的内容和`MainBody.tex`中的内容要保持一致，确保编译时不会出现缺漏。
5. 编译！使用`xelatex->bibtex->xelatex->xelatex`进行编译。
6. 再次确认生成的PDF文件格式符合学院最新模板要求。

## 零碎注意事项

1. 编译过程中可能出现很多warining，如果不想让某类warning显示，可以先看这个warning的编号，比如`19: Use "'" (ASCII 39) instead  of "´" (ASCII 180).`的编号就是19，之后在文件最上面，`%!TEX root = ../MainBody.tex`行下面添加`% chktex-file 19`来忽略该警告，其他编号同理。
2. 论文中，图片标题要在图片上面，表格标题要在表格下面（2026年要求）。
3. 毕设论文是本科阶段最后一门课了，希望大家善始善终，认真对待每一个细节，给自己的本科生活画上完美的句号！
